Tokens v2 — Light Precision + Dark Precision

A refined foundation, not a new one. Every v1 token name survives; values are corrected and a small set of new tokens is added. Drop-in file: tokens-v2.css replaces the :root and dark_precision blocks in frontend/src/theme/styles.css.

← CritiqueData surfaceFMEA mockupHandoff notes

01Five commitments

  1. One accent. Desaturated cobalt. Interaction states (--accent-hover, --accent-active) are tokens — filter: brightness() hacks retire.
  2. Borders-only depth. Shadows exist for two floating layers (popover, toast) plus the focus ring. --shadow-rail-active is now none; both decorative accent gradients are deleted.
  3. A monotonic text ramp. v1’s WCAG fix left --text-faint (#5e6d81) darker than --text-muted (#617289) — the hierarchy was inverted. v2 restores four measured tiers, all AA.
  4. Strict 4px spacing. --space-2-5 (10px) is deprecated to 8px — table density improves as a side effect.
  5. Radius capped at 8px, pills retired. Chips become 4px rectangles; 999px survives only on the progress bar. 12px rail buttons join the system at 6px.

02Surfaces & lines

Four surfaces with named roles — the v1 trio of near-identical grays (surface-muted / surface-soft / section-surface-decoration) had no rule for which to use where.

--surface-muted #F6F7F9 / #1C212AHover tint only. Rows, ghost buttons.

Dark surfaces step up in lightness toward the user: well #12161D → bg #101318 → surface #171B22 → hover #1C212A. Borders carry structure; nothing glows.

Placement rule: semantic color appears as a 6px dot, a text token, or an 18px count badge — never as a whole-surface wash, and never on category data (workflow badges, column-name chips, INFO log lines are gray).

05Depth — one strategy, demonstrated

Docked

Panels, cards, rails, the log strip: 1px --line, flat. Elevation is expressed by surface role, not blur.

Floating

Menus, command palette, toasts: --shadow-popover / --shadow-toast — the only shadows in the system.

Focus ring: 0 0 0 2px accent at 35–45% — the v1 ring (8% alpha) was invisible to the keyboard users this app is built for.
