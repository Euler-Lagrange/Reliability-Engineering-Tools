## 5. Load-bearing domain context (do NOT re-derive or "fix")

**Failure Rate Linker — three distinct quantities** (Jacob was emphatic about not conflating them):
- **Part failure rate (λ)** — the real failures/time number from the Prediction file → `FR_Clean` / `Part_FR` / `Mode_FR` / `Function_FR`.
- **Failure Mode Ratio (FMR)** — the 0–1 decimal, how often a mode happens, validated to sum to 1.0 **per instance**. The code has a firm "do NOT group FMR by base RefDes" comment — leave it.
- **Part Usage** — the fraction (e.g. 1/2) that splits a part's λ across its instances.

**Circuit-block roll-up rule:** a block row (multiple RefDes in the cause, or `FMEA Level` = Circuit/Function Block) is an **aggregate**, not an independent part. Its λ = the **sum of its components**, and it is **excluded from the function total** (else double-count). Children attach by **shared `FMEA-ID` prefix** (the generator builds ids as `{group}-{refdes}-{mode}`). A block can legitimately have a single component. Reuse `common/fmea_utils.classify_fmea_rows` (BOM Compare already does).
